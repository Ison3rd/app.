# AnimatorChat - WhatsApp-like Creative Collaboration Hub

A modern, WhatsApp-inspired chat application designed specifically for animators and creative professionals working on anime projects.

## 🎨 Features

### Core Chat Features
- **Real-time messaging** with smooth animations
- **Media sharing** (images, videos, audio, animations)
- **Voice messages** with waveform visualization
- **File uploads** with drag-and-drop support
- **Group chats** for project teams
- **Individual chats** for one-on-one collaboration

### Animator-Specific Features
- **Project-based organization** with dedicated channels
- **Animation file support** (.gif, .mp4, .mov, .avi)
- **Character design sharing** with preview functionality
- **Voice acting collaboration** with audio recording
- **Storyboard uploads** and discussions
- **Frame-by-frame review** capabilities

### Professional Tools
- **Video/Voice calls** for team meetings
- **Screen sharing** for animation reviews
- **Status updates** for project progress
- **Online presence** indicators
- **Search functionality** across all conversations
- **File organization** by project and type

## 🚀 Getting Started

### Installation
1. Save the `animator-chat.html` file to your project directory
2. Open in any modern web browser
3. No additional setup required - it's a standalone application

### Integration with AnimeVerse Empire
To integrate with the main platform:

1. **Add to Navigation**: Include a chat button in the main dashboard sidebar
2. **Embed as Module**: Use iframe or direct integration
3. **Share User Data**: Pass user information between platforms
4. **Project Linking**: Connect chats to specific anime projects

## 📱 Interface Overview

### Left Sidebar
- **User Profile**: Shows current user with role (Animator, Storyteller, etc.)
- **Search Bar**: Find conversations quickly
- **Tab System**: Switch between Chats, Projects, and Status
- **Chat List**: All conversations with unread counts and previews

### Main Chat Area
- **Chat Header**: Current conversation info with call buttons
- **Messages**: Rich media support with timestamps
- **Input Area**: Text, voice, and file sharing controls

### Special Message Types
- **Media Messages**: Images and videos with preview
- **Voice Messages**: Audio with playback controls
- **File Messages**: Documents with download options
- **Animation Files**: Specialized handling for animation formats

## 🎭 User Roles & Permissions
