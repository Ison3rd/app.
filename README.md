# Team - Creative Collaboration App

A mobile-responsive web application for creative team collaboration, featuring role-based registration and a modern dark theme UI.

## Features

### 🎭 Role Selection
- Choose from 6 creative roles:
  - President
  - Storyteller
  - Voice Over Artist
  - Background Creator
  - Producer
  - Animator

### 📱 Mobile-First Design
- Responsive design optimized for mobile devices
- Dark theme with gradient backgrounds
- Smooth animations and transitions
- Touch-friendly interface

### 🔐 User Registration
- Email validation
- Username and password requirements
- Role-based account creation
- Form validation with error messages

### ✨ Interactive Features
- Role selection with visual feedback
- Screen transitions with animations
- Form submission with loading states
- Success notifications
- Touch feedback for mobile devices

## Getting Started

1. Open `index.html` in your web browser
2. Select your desired role from the available options
3. Click "Create Account" to proceed to registration
4. Fill in your details and submit the form
